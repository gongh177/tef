核心功能

全方位自定义体验

从字体到玩法，TEFManager 让每一个细节都能按你的喜好调整

字体自定义

自由替换游戏内字体，支持 TTF/OTF 格式。无论是像素风还是手写体，都能完美适配泰拉瑞亚的 UI 界面。

语言自定义

内置多语言支持，可加载自定义语言包。轻松创建或分享你的专属翻译，让游戏说你想说的话。

材质自定义

一键替换游戏纹理包，支持高清材质。从方块到角色，从背景到特效，全部可以重新定义视觉风格。

玩法自定义

通过模组系统扩展游戏玩法，支持模组依赖管理、冲突检测与一键排序。打造独一无二的冒险体验。

常见问题

TEFManager 目前支持泰拉瑞亚 1.4.x 及以上版本，包括最新的 1.4.5.6。我们会持续跟进官方更新，确保兼容性。
打开 TEFManager 后，菜单选择对应的自定义模块（字体/语言/材质），点击"导入"按钮选择你的资源文件即可。软件会自动处理格式转换和备份。
TEFManager 仅修改本地客户端资源，不涉及服务器端数据篡改。单人游戏和非官方服务器完全安全。在加入官方服务器前建议恢复原版资源以避免风险。
TEFManager 内置运行日志，把日志丢给ai即可。
欢迎所有形式的贡献！你可以通过 GitHub 提交 Pull Request 参与代码开发，或在社区论坛发布你的语言包和材质包。
